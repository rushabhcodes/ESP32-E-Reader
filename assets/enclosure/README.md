# Enclosure preview assets

The GLB files in this directory are generated by
`scripts/generate-enclosure.py`. `index.circuit.tsx` uses the battery envelope,
display panel, front bezel, button caps, rear tray, and power slider in the 3D
assembly. `rear-cover.glb` is an optional translucent back preview.

The current visual shell is **68 × 109.5 mm** around a **62.5 × 95.08 mm** PCB.
Four separate caps cover the bottom-side SKRPACE010 tactile switches. The
nominal 29 × 36 × 4.75 mm battery envelope sits behind the PCB. Board
coordinates use the original (0, 0) anchor: the component side is +Z and the
display/button side is −Z.

The display model represents the specified EastRising ER-EPD3.97-1RY panel
outline (56.24 × 96.62 × 0.9 mm) and active area (51.84 × 86.40 mm). It is
authored relative to J2, where `assembly.screen` attaches it. The FPC fold is
omitted.

These meshes reconstruct the appearance shown in the
[source project's photos](https://github.com/IS7V4N/ESP32_E-Reader/tree/main/Hardware/Images)
using this repository's PCB and part coordinates. The source project does not
publish its enclosure CAD. These visual models have not been validated for
printing, button travel and retention, display clearance, battery support, or
assembly fit.

Regenerate the models with
`blender --background --python scripts/generate-enclosure.py`.
After building the circuit, regenerate `front-preview.png` and
`power-access-preview.png` with their corresponding scripts in `scripts/`.
